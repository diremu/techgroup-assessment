# Project Name
TechBridge Intern Management Platform developed by Diremu

## Project Description
This platform is a way for interns and admins alike to manage, update and monitor tasks and challenges for interns of TechBridge. It is an avenue to be familiarized with challenges and tasks in a path of your choice.

## Technologies Used
HTML
CSS
Javascript
Node.js
Express.js
REST API
JSON
CORS

## Main Features

- Built a dashboard allowing interns to know critical information about their tasks, indicate completion, and plan ahead
- Designed a Home page and programs page for seamless onboarding into the internship program while providing information of the program.
- Implemented an Internship roadmap that detailed all tasks and their corresponding duration for the interns.
- Set up a Node.js and Express REST API that supplied details to the frontend on request.

## Project Setup
To run the project, you need to run the following commands:

`cd frontend`
and open it in your browser!

To run the backend of the project, run these commands
`cd backend`

`npm install`

`npm run dev`

And the project is running!
